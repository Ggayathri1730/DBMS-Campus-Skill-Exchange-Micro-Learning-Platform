# Faculty Demo Checklist

## Before the demo

- [ ] backend running
- [ ] frontend running on 5174
- [ ] MySQL connected and healthy
- [ ] demo accounts available
- [ ] one student can register a new account
- [ ] matching page loads
- [ ] request flow works
- [ ] course flow works
- [ ] progress logging works
- [ ] review flow works

## Demo flow

1. Open Home page.
2. Log in as Maya.
3. Show profile and skill counts.
4. Open Matching.
5. Show reciprocal or one-way match cards.
6. Send a request.
7. Log in as Aarav.
8. Accept the request.
9. Return to Maya and complete the exchange.
10. Submit a review.
11. Open Courses and enroll.
12. Open Progress and log a session.
13. Log in as admin and show skill/course management.
14. Refresh pages to show persistence.

## Expected visible results

- matching cards are real and data-backed
- request statuses update correctly
- course enrollments persist
- progress totals update
- review appears under received/given
- admin can add/edit protected records
- logout redirects to login
